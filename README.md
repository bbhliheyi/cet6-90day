# 大学英语六级 · 90天通关训练营

面向全国考生的原创CET6学习网站，默认展示吉林省2026年下半年考试提醒。项目不复制开源学习软件代码或商业题库，不依赖大模型服务。

## 当前可用功能

- 2026年下半年笔试倒计时与吉林报名提醒。
- DAY 1—90完整学习路线、任务签到、连续天数和本周完成统计。
- 5278词开放大纲词表、1253个六级重点标记、考试文本词频、71条词根/词族/同义替换/写译语境扩展、63条原创高频搭配，支持五种背词模式、点击/滑动评级、间隔复习和10词考核。
- 词表浏览支持搜索全部词库、主题筛选、学习状态筛选、到期复习筛选；个人统计显示累计正确率和连续复习天数。
- 原创听力、阅读、写作、翻译和口语训练样例。
- 44个带来源标签的原创专项训练单元，覆盖听力、仔细阅读、选词填空、长篇匹配、写作、翻译和口语。
- 原创完整测试：固定题序、130分钟倒计时、分段作答、离开后继续、交卷分项统计和历史留存；明确不等同官方真题。
- 首页显示“继续上次学习”、今日达标进度和7天备份提醒。
- 独立的核心句与磨耳朵模块：核心句用于输出迁移，磨耳朵使用长对话、篇章、报道和讲座，并按五步法记录进度。
- 浏览器朗读、写译计时、本地口语录音和影子跟读回听。
- 富文本笔记、图片、贴图和自动保存。
- 本机多账户：创建、口令登录、切换、退出和删除账户，每个账户独立保存进度、笔记与录音。
- 旧版访客进度自动迁移，创建账户时可复制当前访客进度。
- Supabase邮箱云账户、跨设备学习状态同步、离线补传和版本冲突保护。
- 当前账户的JSON学习数据导入导出。
- PWA安装、离线缓存和响应式页面。
- 官方网站、吉林公告和英语学习资源索引。

## 本地运行

```bash
npm run check
npm run build
npm run serve
```

然后访问 `http://localhost:4173/`。`serve` 命令会打开构建后的 `dist/`，首次加载后支持离线打开核心页面。

## 云同步初始化

1. 在 Supabase 项目的 SQL Editor 中运行 `supabase/schema.sql`。
2. Authentication → URL Configuration 中设置本站地址与允许的重定向地址。
3. 面向非项目成员开放邮箱注册前，配置自定义SMTP；未配置时可先用项目团队邮箱测试。
4. 网页只包含 Project URL 与 Publishable key，不包含数据库密码、Secret key 或 `service_role`。

云端同步任务、词汇、核心句、磨耳朵、练习、草稿和笔记。录音暂时只保存在当前设备。

## 发布

推送到 `main` 后，GitHub Actions自动检查并部署 `dist/` 到GitHub Pages。

## 数据与版权

- 学习进度和笔记按本机账户隔离，保存在用户浏览器。
- 本机账户口令通过PBKDF2哈希保存，不存储明文；这不等同于服务器账户安全。
- 口语与影子跟读录音按账户隔离，保存在本地IndexedDB。
- JSON备份暂不包含录音大文件。
- 未登录云账户时，跨浏览器或清理浏览器数据前仍需导出备份。
- 云账户启用后仍采用本地优先策略；离线期间的操作会在恢复联网后补传。
- 官方与第三方资源只提供入口，不镜像完整内容。
- 当前训练题、示例句和页面代码均为本项目独立制作。
- 官方真题只提供官方入口索引；请使用本人合法取得且有权使用的材料，不上传商业扫描件或付费题库。

详细执行方案见 `EXECUTION_PLAN.md`，来源登记见 `SOURCES.md`。
